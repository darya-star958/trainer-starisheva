# Тренажёр по теме «Логические выражения и таблицы истинности»

**Автор:** Старишева Дарья Александровна, группа 5117241, 2026 год.

**Ссылка на опубликованную версию:** https://darya-star958.github.io/trainer-starisheva/

## Назначение

Тренажёр предназначен для учащихся 10 класса для отработки навыков вычисления логических выражений и построения таблиц истинности.

## Состав проекта

* `src/lib/` — предметная логика.
* `src/hooks/` — кастомные хуки.
* `src/components/` — компоненты.
* `src/context/` — контексты.
* `public/data/tasks.json` — банк задач.
* `public/img/` — иллюстрации.
